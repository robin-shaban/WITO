Accessibility

WITO material conforms to the Web Content Accessibility Guidelines, version 2.2, at level AA. Conformance is verified before release rather than asserted, and nothing is published that fails.

Conformance status

Partially conformant. This site was checked on 20 August 2026 against WCAG 2.2 level AA. Every page passed. The check does not extend to the three PDF documents the site links to, which are not tagged; that limitation is recorded below.

What was checked, and what was found

Every page of the site, with all collapsed sections opened so that their content was measured too.

The focus indicator is a two pixel solid outline in Gable Green, offset by two pixels. Several criteria do not apply: the site contains no audio, no video, no time limits, no motion-triggered behaviour, no content that updates on its own, and no forms.

Measures taken

Only approved foreground and background colour pairs are used. Colour is never the only carrier of meaning: every series, state, or category is also distinguished by a label, a position, or a pattern. The figure is vector with live text rather than an image of text, it carries a text alternative, and the same information is repeated in a data table beside it. Minimum text size on the web is 12 pixels. The site runs no JavaScript, so nothing depends on scripting being available. Collapsible sections use the browser's own disclosure element, which is operable by keyboard without script.

Known limitations

The PDF documents are not tagged. The statutes, the issue paper, and the working paper each carry a real text layer, embedded fonts, and a declared document language, so their text can be read aloud and selected. None carries a structure tree, so a screen reader cannot navigate them by heading, and reading order is inferred rather than declared. WITO intends to republish all three from tagged source.

The two research publications are available in English only. The site itself is published in English and French. Where a French text of an instrument exists, that text governs.

Content inside a collapsed section is not reached by the browser's in-page search in every browser. This affects the Participate page. Both sections can be opened, and opening them is a single keystroke or click.

Feedback

Anyone who has difficulty using this site is invited to tell WITO, and WITO will respond. Please use the contact page.
